A fast **data-quality triage** tool. Load any CSV and it profiles every column so you know what you're dealing with before you trust the file.

## ✨ What it reports

| Per column | |
|---|---|
| 🏷️ **Type detection** | number / text / date / boolean, inferred from the values |
| 🕳️ **Missing values** | count + % empty, with a visual gap bar |
| 🔑 **Uniqueness** | unique-value count; flags likely keys and constant columns |
| 📐 **Numeric stats** | min, max, mean, median, sum |
| 📊 **Top values** | the most common values, as a mini bar chart |

Plus a dataset overview: row count, column count, duplicate rows, total empty cells.

## 🔒 Private by design

Everything runs **100% in your browser** — the file is parsed locally and never uploaded. Use it on real data safely, or click **Load sample data**.

## 🧰 Tech

- **Vanilla HTML / CSS / JavaScript** — no frameworks, no dependencies, one `index.html`
- Robust CSV parsing (quoted fields, embedded commas & newlines, BOM)
- Hosted free on **GitHub Pages**

## ▶️ Run locally

```bash
start index.html      # Windows — no build step
```
